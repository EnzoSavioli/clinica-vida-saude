# Clínica Vida & Saúde

Site institucional em HTML5 com 4 páginas integradas.

## Páginas
- index.html
- especialidades.html
- equipe.html
- atendimento.html

## JavaScript
O arquivo `assets/js/script.js` controla o botão de tema claro/escuro. A escolha fica salva no navegador com `localStorage`, então o tema continua selecionado ao trocar de página.

## Como abrir
Abra `index.html` no navegador ou use o Live Server no VS Code.
